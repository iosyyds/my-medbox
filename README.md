# 我的药盒 - 个人药品记录网站

一款轻量化的个人药品管理工具，帮你记录家里的常备药，再也不用担心"看到药想不起来治什么"

## 功能特性

- 拍照上传药品图片，自动压缩优化
- 完整记录药品信息：名称、功效、用法用量、禁忌、保质期、厂家
- 智能搜索：支持药名、功效、症状关键词模糊搜索
- AI关键词生成：输入药名或症状，自动推荐搜索关键词
- 图片搜药：拍照匹配已记录的药品
- 过期提醒：自动识别过期/即将过期药品，首页醒目提醒
- 多维度筛选：按有效期、药品类型筛选
- 数据本地存储：所有数据保存在浏览器 localStorage，隐私安全
- 响应式设计：手机、平板、电脑完美适配
- 极速加载：纯静态页面，图片压缩，无网络也能查看已记录药品

## 技术栈

- 纯前端：HTML + CSS + JavaScript（单文件）
- 无后端、无数据库、无构建工具
- 数据存储：浏览器 localStorage
- 图片处理：Canvas 前端压缩

## 部署方式（GitHub Pages）

1. Fork 或使用本仓库
2. 进入仓库 Settings → Pages
3. Source 选择 `Deploy from a branch`
4. Branch 选择 `main`，文件夹选择 `/ (root)`
5. 点击 Save，等待部署完成
6. 访问 `https://你的用户名.github.io/my-medbox/`

## 使用说明

1. 点击右下角 **+** 按钮添加药品
2. 可拍照或上传药品图片，填写药品信息
3. 搜索栏支持关键词搜索，也可点击 **AI关键词** 智能生成
4. 点击相机图标可通过图片搜索已记录药品
5. 药品卡片会显示有效期状态（绿色=正常，黄色=即将过期，红色=已过期）
6. 点击药品卡片查看详情，可编辑或删除

## 数据安全

- 所有数据仅存储在你自己的浏览器中，不上传任何服务器
- 清除浏览器数据会导致记录丢失，建议定期截图备份重要信息
- 更换设备或浏览器后数据不会同步，需重新录入

## 自定义扩展

- 可在 `generateKeywords()` 函数中扩展更多药品和症状关键词库
- 可对接药品识别 API（需后端代理，避免 API Key 暴露）
- 可添加数据导出/导入功能（JSON 格式）
